Use the `portfolio-auditor` subagent.

Audit this repository across:

- security and Firestore access;
- broken behavior;
- Next.js architecture and client/server boundaries;
- TypeScript safety;
- duplicated content/data;
- responsive UX;
- accessibility;
- SEO and metadata;
- performance;
- dependency/tooling health;
- dead code and maintainability.

Do not edit files.

Return P0/P1/P2 findings with file paths, evidence, risk, and the smallest recommended fix. Separate facts from preferences and list any personal-content questions that require owner confirmation.
